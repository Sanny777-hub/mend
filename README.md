mend is one patch tool for every AI edit format: unified diff, SEARCH/REPLACE blocks, V4A patches, and JSON tool calls. Give it a patch on the command line or stdin and it applies the edits to your files, atomically — any failure means nothing is written.

## Run it

```sh
node main.ts [PATCH]
```
